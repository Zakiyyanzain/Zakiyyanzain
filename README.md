# Zakiyyan Zain Alkaf, S.T., M.Sc.

Data scientist (BNSP) and industrial engineer. I build risk, forecasting and anomaly-detection models for solar PV in the tropics.

## What I work on

- Climate risk and site screening for PV
- PV yield and investment-risk simulation (pvlib)
- Production anomaly detection
- Weather-aware cleaning and maintenance scheduling

## Selected work

- PVIRI, Photovoltaic Installation Risk Index (Theoretical and Applied Climatology, Scopus Q2): code and data in this profile and on Zenodo
- Anomaly detection for solar energy production (Advances in Technology Innovation, Scopus Q3)
- Climate risk in PV investment appraisal (CENTIVE 2026): code and data on Zenodo
- Monsoon rain as a free cleaning resource: code and data on Zenodo
